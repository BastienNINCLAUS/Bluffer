# Règles de Bluffer

## Le principe
- L'écran pose une **question**. Personne ne connaît la vraie réponse.
- Chaque équipe invente une **fausse réponse** crédible, en secret, depuis son téléphone.
- L'animateur choisit avant la partie les **thèmes** des questions (insolite, histoire, Noël…).
- L'écran mélange la vraie réponse et les fausses, puis tout le monde **vote** pour celle qu'il pense vraie.
- Les vraies réponses sont déjà étonnantes : pour piéger les autres, soyez plausibles !

## Inventer sa réponse
- Écrivez une fausse réponse courte et crédible, puis envoyez-la.
- Si vous connaissez la vraie réponse, inventez-en une autre : la vraie réponse est refusée.
- Dans une équipe, discutez dans le **tchat**, appuyez sur **Proposer** sur le message choisi, puis chacun appuie sur **Valider**.
- La réponse part quand **tous** les membres ont validé. Une nouvelle proposition remet les validations à zéro.

## Voter
- Les réponses sont numérotées. Choisissez celle que vous pensez vraie.
- Il est **interdit de voter pour sa propre réponse**.
- En équipe, le vote se décide comme la réponse : proposition, puis validation de tous.

## Le temps
- Il n'y a pas de minuteur au départ.
- Dès qu'une équipe a validé, les autres ont **{{delai}} secondes** pour finir.
- Une équipe qui n'a rien validé à temps ne marque pas de point pour cette étape.

## Les points
- **+2 points** pour chaque vote reçu sur votre fausse réponse : vous avez piégé quelqu'un !
- **+1 point** si vous avez voté pour la vraie réponse.
- Deux réponses identiques restent deux réponses : chaque vote compte pour la réponse choisie.
- Les scores s'affichent après chaque question.

## Le déroulement
- Les étapes avancent quand tout le monde appuie sur **Prêt** sur son téléphone, ou depuis l'écran.
- Les résultats se dévoilent réponse par réponse, la vraie réponse en dernier.
- L'équipe qui a le plus de points à la dernière question gagne la partie.
